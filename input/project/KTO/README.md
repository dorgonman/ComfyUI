# KTO ComfyUI Project Inputs

Project-specific source, reference, staged, and approved images for KTO
workflows.

The current Key Visual source is stored under:

```text
source/key_visual/Tamao/OUT-TAM-001/v001/
```

HeroBody experiment handoffs will use:

```text
stage/character/Tamao/HeroBody_Bust/<stage>/vNNN/
stage/character/Tamao/HeroBody_BodyCore/<stage>/vNNN/
approved/character/Tamao/<artifact>/vNNN/
```

Workflow output must be reviewed before it is copied from
`output/project/KTO` into a stage or approved directory.
